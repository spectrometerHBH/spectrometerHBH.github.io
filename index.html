Bohan Hou

I build machine learning systems for efficient AI, with an emphasis on compiler-based approaches and automation for GPU kernel programming, LLM inference, and agentic kernel optimization.

I am a researcher at Carnegie Mellon's Catalyst Lab, advised by Prof. Tianqi Chen. I am completing my Ph.D. in Computer Science at Carnegie Mellon University.

Highlights include: TIRx, an open compiler stack for frontier ML kernels; TIRx Harness, an open compiler harness for agentic GPU programming; Event Tensor, a unified abstraction for compiling dynamic megakernels; and TensorIR, a compiler abstraction for automatic tensor program optimization. These projects explore how compilers, hardware-native abstractions, and automated optimization can make high-performance kernels easier to develop and evolve.

Projects

TIRx: An Open Compiler Stack for Evolving Frontier ML Kernels [repo]
TIRx is an open-source, hardware-native DSL and compiler for ML kernels, built on Apache TVM. It compiles to GPUs and specialized AI accelerators today and is designed to grow with future hardware generations. The same design serves expert-written kernels, agent-generated kernels, and megakernel systems.

TIRx Harness: An Open Compiler Harness for Agentic GPU Programming [kernels] [harness] [post]
TIRx Harness is an open compiler harness for agentic GPU programming. 2.94× KDA fwd, 6.84× KDA bwd, 2.59× MSA prefill, 3.99× MSA decode, 1.33× KDA decode, 1.71× MLA, 1.68× VSA — just by pressing Enter.

MLC-LLM: Machine Learning Compilation for Large Language Models [repo]
MLC-LLM is a universal solution that allows any language models to be deployed natively on a diverse set of hardware backends and native applications, plus a productive framework for everyone to further optimize model performance for their own use cases.
